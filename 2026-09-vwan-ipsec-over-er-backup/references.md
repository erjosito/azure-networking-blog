# References: Backing up Azure Virtual WAN IPsec over ExpressRoute with Internet VPN

## Source lab

The `erjosito/net-lab-builder` repository is public, but the completed lab path
was not present on its public `main` branch when this draft was created.
Source-lab deep links are intentionally omitted rather than publishing broken
links. The local evidence used for this post was sanitized and excludes
credentials, pre-shared keys, subscription identifiers, resource GUIDs,
service keys, public endpoint values, and raw sensitive dumps.
